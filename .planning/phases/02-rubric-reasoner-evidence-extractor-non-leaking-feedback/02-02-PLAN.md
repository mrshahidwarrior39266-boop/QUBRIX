    Create `core/feedback_engine.py` with class `FeedbackEngine`.
    Include methods:
    - `generate_feedback(criterion_evaluations: list[dict], model_answer: str) -> dict`:
      Analyzes evaluations where `status` is 'PARTIAL' or 'NONE'.
      Generates constructive, socratic guidance for each missed point.
      If all criteria are 'FULL', generates positive reinforcement ("Strong understanding demonstrated across all required concepts.").

      Verifies that no verbatim n-grams ($\ge 4$ words) from `model_answer` appear in `feedback_text`.
      Returns True if safe (no leakage), False if leakage detected.
    - If leakage is detected, automatically sanitizes the feedback to abstract conceptual guidance.
  </action>
