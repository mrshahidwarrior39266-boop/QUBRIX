  <name>Task 1: Build decoupled RegradingEngine</name>
  <files>core/regrading_engine.py</files>
  <action>
    Create `core/regrading_engine.py` with class `RegradingEngine`.
    Include:
    - Method `regrade_evaluation(criterion_evaluations: list[dict], new_weights: dict[str, float]) -> dict`:
      Applies `new_weights` directly to the cached fulfillment status:
      `awarded = new_weights[cid] * multiplier`.
      Calculates `new_total` and `new_max`.
      Executes in < 1 millisecond.
    - Method `regrade_batch(df: pd.DataFrame, new_weights: dict[str, float]) -> pd.DataFrame`:
      Applies `regrade_evaluation` across all rows in `df`.
      Produces updated `regraded_score` and `regraded_pct`.
  </action>

    <automated>python -c "from core.regrading_engine import RegradingEngine; re = RegradingEngine(); c_evals = [{'criterion_id': 'C1', 'status': 'FULL', 'multiplier': 1.0, 'awarded_points': 2.0, 'max_points': 2.0}]; res = re.regrade_evaluation(c_evals, {'C1': 4.0}); assert res['new_total'] == 4.0; print('Regrading test passed')"</automated>
  </verify>
  <done>RegradingEngine performs sub-millisecond score recalculation from cached fulfillment states.</done>
</task>

<task type="auto">
  <name>Task 2: Build Before-and-After Score Diffing Generator</name>
  <files>core/regrading_engine.py</files>
  <action>
    Add method `compute_score_diff(df: pd.DataFrame, new_weights: dict[str, float], human_col: str = 'human_score') -> dict` in `RegradingEngine`.
    Computes per-student comparison:
    - `student_id`: ID
    - `old_score`: Previous mark
    - `new_score`: Updated mark
    - `score_delta`: `new_score - old_score` (e.g. +1.5, -0.5)
    - `delta_status`: 'Increased' (green), 'Decreased' (red), 'Unchanged' (gray)
    - `explanation`: Generates human-readable justification (e.g. "Gained +1.0 marks: C1 weight increased from 2.0 to 3.0").
    Also recomputes updated QWK vs `human_score` and returns:
    `{"diff_dataframe": pd.DataFrame, "old_qwk": dict, "new_qwk": dict, "average_delta": float}`.
  </action>
  <verify>
    <automated>python -c "import pandas as pd; from core.regrading_engine import RegradingEngine; re = RegradingEngine(); df = pd.DataFrame([{'student_id': 'S1', 'rubric_score': 2.0, 'human_score': 3.0, 'rubric_results': {'criterion_evaluations': [{'criterion_id': 'C1', 'status': 'FULL', 'multiplier': 1.0, 'max_points': 2.0}]}}]); diff_res = re.compute_score_diff(df, {'C1': 3.0}); assert diff_res['diff_dataframe']['score_delta'].iloc[0] == 1.0; print('Diff computation verified')"</automated>
  </verify>
  <done>compute_score_diff produces before/after delta tables with explanations and updated QWK.</done>
</task>
