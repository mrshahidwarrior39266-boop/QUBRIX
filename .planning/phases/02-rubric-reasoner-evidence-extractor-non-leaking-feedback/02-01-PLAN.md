  <files>core/rubric_evaluator.py</files>
  <action>
    Create `core/rubric_evaluator.py` implementing `RubricEvaluator`.
    Include:
    - Method `evaluate_answer(question: str, model_answer: str, rubric: list[dict], student_answer: str) -> dict`:
      Evaluates each criterion in `rubric`.
      Returns:
      ```python
      {
        "criterion_evaluations": [
          {
            "criterion_id": "C1",
            "description": "...",
            "max_points": 2.0,
            "status": "FULL",        # "FULL" (1.0), "PARTIAL" (0.5), or "NONE" (0.0)
            "awarded_points": 2.0,
            "evidence_quote": "...",  # Exact verbatim phrase from student_answer or ""
            "is_quote_verified": True, # True if evidence_quote in student_answer
            "evaluator_note": "..."
          }
        ],
        "total_awarded": float,
        "total_max": float,
        "overall_percentage": float
      }
      ```
    - Verbatim verification logic: verifies `quote.strip() in student_answer`. If not found, flags `is_quote_verified = False` and logs warning.
    - LLM connector supporting Google Gemini API (structured JSON mode via `google-genai` or `google.generativeai`).
    - Robust local heuristic evaluator fallback: if `GEMINI_API_KEY` is not present, uses semantic term overlap and sentence splitting to extract matching spans deterministically, ensuring 100% offline demo resilience.
  </action>
